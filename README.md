# 🌊 RaftCraft

**RaftDP** is a Minecraft datapack inspired by **Raft**, bringing ocean survival and crafting gameplay into Minecraft.

### ✨ Features

* 🌊 Ocean-based survival
* 🪵 Floating platforms and debris
* 🪝 Custom hook system
* 💧 Thirst and water system
* 🔨 Custom tools and equipment
* 📦 Custom loot and resource collection
* 🎨 Custom items, models, and UI
* ⚙️ Fully datapack-based gameplay systems

### 🛠️ Development

This project is currently **in development**.

New mechanics, systems, items, and improvements are continuously being added.
